# Getting help with Eddyter

Pick the channel that fits your question, and you'll get the fastest answer.

| I want to… | Go to |
|---|---|
| Learn how to set up or use Eddyter | 📘 [Documentation](https://eddyter.com/docs) |
| See a working project for my framework | 💡 [Examples](https://github.com/EddyterAI/examples) |
| Ask a how-to question | 💬 [Discussions → Q&A](https://github.com/EddyterAI/eddyter/discussions/categories/q-a) |
| Chat with the team and community | 🎮 [Discord](https://discord.com/channels/1457444571104542803/1457444572081819690) |
| Report a bug | 🐛 [Bug report](https://github.com/EddyterAI/eddyter/issues/new/choose) |
| Request a feature | ✨ [Feature request](https://github.com/EddyterAI/eddyter/issues/new/choose) |
| Report a security issue | 🔒 [Security policy](https://github.com/EddyterAI/.github/blob/main/SECURITY.md) (never a public issue) |
| Ask about billing, licensing or enterprise plans | ✉️ support@eddyter.com |

## Before you ask

1. **Update** to the latest version: `npm install eddyter@latest`
2. **Check the stylesheet import:** `import 'eddyter/style.css'` is required.
3. **Check your API key** in the [dashboard](https://www.eddyter.com/user/license-key) and make sure it's available to the browser (for example `NEXT_PUBLIC_` in Next.js).
4. **Search** the [docs](https://eddyter.com/docs), [issues](https://github.com/EddyterAI/eddyter/issues?q=is%3Aissue) and [Discussions](https://github.com/EddyterAI/eddyter/discussions).

## Asking a good question

Include:

- The package and version (for example `eddyter@1.4.28`)
- Your framework and version (for example Next.js 15, App Router)
- What you expected and what happened instead
- A short code sample or a StackBlitz / CodeSandbox link
- Any errors from the browser console

**Never share your API key.** Replace it with `YOUR_API_KEY`.
